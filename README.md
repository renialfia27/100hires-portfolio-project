# 100hires-portfolio-project
## Tools Installed
- **Cursor IDE** — AI-powered code editor (cursor.com)
- **Claude Code** (Cursor Extension) — Anthropic's AI coding assistant
- **Codex by OpenAI** (Cursor Extension) — OpenAI's coding agent

## Steps Completed
1. Downloaded and installed Cursor IDE on Windows
2. Enabled Developer Mode on Windows to allow trusted app installs
3. Installed Claude desktop app (later corrected, see Issues)
4. Installed Claude Code extension via Cursor Extensions (Ctrl+Shift+X)
5. Installed Codex – OpenAI's coding agent via Cursor Extensions
6. Created a GitHub account and set up this public repository
7. Created and edited this README.md to document the process

Total time: approximately 10–15 minutes, depending on internet connection speed.

## Issues I Ran Into & How I Solved Them

**1. Developer Mode error during Claude install**
When installing the Claude desktop app, a prompt appeared saying trusted app 
installs needed to be enabled. I clicked "Yes" to open Settings, navigated 
to System → For Developers, and turned on Developer Mode. After confirming 
the prompt, the installation proceeded successfully.

Note: I later realized I had installed the wrong thing — the task required 
the Claude Code extension inside Cursor, not the standalone Claude desktop app. 
This mistake is documented in Issue #2 below.

**2. Confusion between Plugins, Extensions, and the Claude desktop app**
I initially misunderstood the instructions. When asked to add the "Claude Code" 
extension in Cursor, I accidentally installed the Claude desktop app instead 
of searching for the extension inside Cursor's Extensions panel (Ctrl+Shift+X). 
I also didn't know the difference between Plugins and Extensions in Cursor — 
I assumed they were the same thing.

I resolved this by asking Claude (the AI) directly how to find the Extensions 
panel, which is accessed via Ctrl+Shift+X — a separate Marketplace completely 
different from the Plugins menu.

This was a good reminder that in technical environments, small differences 
in terminology matter a lot.

**3. Codex requires a ChatGPT account**
After installing Codex, I found it requires a ChatGPT Plus or Pro account 
to fully use. I installed the extension and noted this as a limitation 
for free-tier users.

## Reflection
I came into this task with zero experience using developer tools or GitHub. 
As a marketing professional, I had never needed a code editor before — 
so this was entirely new territory.

What surprised me most was how approachable these tools are becoming. 
When I got stuck, I used Claude to ask questions and get guidance in plain 
language, which made the learning curve much more manageable.

Going through this process changed how I think about AI tools in marketing. 
Growth marketers are increasingly expected to work alongside engineers, 
analyze data, and build automated workflows. Understanding tools like 
Cursor, Claude, and Codex — even at a basic level — makes that collaboration 
easier and faster.

I also realized that the skill 100Hires is really testing here isn't 
technical ability. It's resourcefulness: the ability to encounter something 
unfamiliar, figure it out, and document what you learned. That's a skill 
I use every day in marketing.
